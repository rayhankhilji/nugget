## Fonts

All fonts are bundled in `public/fonts/`, and no font is loaded from a third party.

| Font | Use | Licence |
| --- | --- | --- |
| Fraunces (variable: opsz, wght, SOFT, WONK), by the Fraunces Project Authors (Undercase Type) | Display: headlines, hero, prices, wordmark | SIL OFL 1.1 (`public/fonts/OFL-fraunces.txt`) |
| Geist, by the Geist Project Authors | UI and body | SIL OFL 1.1 (`public/fonts/OFL-geist.txt`) |
| Geist Mono, by the Geist Project Authors | Numbers and labels | SIL OFL 1.1 (`public/fonts/OFL-geist-mono.txt`) |

Fraunces is subset to Latin, keeping all four axes:

```sh
pyftsubset node_modules/@fontsource-variable/fraunces/files/fraunces-latin-full-normal.woff2 \
  --unicodes="U+0020-007E,U+00A0-00BF,U+00D7,U+00F7,U+2013-2014,U+2018-201D,U+2022,U+2026,U+20AC,U+2192" \
  --layout-features='kern,liga,calt,ss01,ss02,lnum,onum,tnum,pnum' --flavor=woff2 \
  --output-file=public/fonts/fraunces.woff2
```
