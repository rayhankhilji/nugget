# Wave Y: v1 evidence

Starts from 308f775 (waves W and X merged, X5 still running). Wave X made Nugget release-ready on paper;
wave Y produces the evidence the v1 exit criteria in `docs/PLAN.md` ask for: real macOS and Windows runs,
real-model numbers, a trustworthy supply chain, a measured first run, and reproducible benchmarks.

| WP | Branch | Package |
|---|---|---|
| Y1 | `y/real-os` | run Nugget for real on macOS and Windows |
| Y2 | `y/real-models` | real-model evaluations |
| Y3 | `y/trust` | trust and supply chain |
| Y4 | `y/first-run` | first run and everyday polish |
| Y5 | `y/dashboards` | reproducible benchmarks in the README, nightly dashboards |
