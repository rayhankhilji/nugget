# Wave EE

Six packages on the integration branch after AA3 (a7b69e1), alongside wave DD. Each lead runs a build layer and a review layer of subagents.

| WP | Branch | Package |
|---|---|---|
| EE1 | `ee/entity-resolution` | EE1: knowledge extraction to entity F1 ≥ 0.8 with a local model. |
| EE2 | `ee/draft-recall` | EE2: drafts that use the facts they need (fact recall ≥ 0.8), with nothing invented. |
| EE3 | `ee/ask-quality` | EE3: Ask (chat over your items) answer quality, measured with real models and improved. |
| EE4 | `ee/security-review-2` | EE4: security review of everything merged since Z4, and fixes. |
| EE5 | `ee/release-readiness` | EE5: release readiness, everything short of the user's keys. |
| EE6 | `ee/ui-polish` | EE6: the desktop app, page by page, at release quality. |
