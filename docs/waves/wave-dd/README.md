# Wave DD

Four packages that do not depend on AA3 (grounding and knowledge extraction, being integrated) and close open PLAN items with real evidence.

| WP | Branch | Package |
|---|---|---|
| DD1 | `dd/wayland-shortcut` | DD1: Double Tap's global shortcut on Wayland. |
| DD2 | `dd/energy` | DD2: energy and battery cost, measured and cut. |
| DD3 | `dd/agent-judgement` | DD3: computer-use judgement: ask when it's ambiguous, and evidence for the triage decision. |
| DD4 | `dd/recall-real-embedder` | DD4: memory recall with a real embedding model. |
